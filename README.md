# ApexPlanet-Cybersecurity-Task1

## ApexPlanet Cybersecurity & Ethical Hacking Internship — Task 1

### Task: Foundations of Cybersecurity & Environment Setup

This repository contains my work and study material for Task 1 of the ApexPlanet Cybersecurity & Ethical Hacking Internship.

## Objectives

- Understand cybersecurity fundamentals
- Learn the CIA Triad
- Study common cyber threats and attack vectors
- Set up a cybersecurity lab environment
- Learn Linux fundamentals
- Understand networking basics
- Study cryptography fundamentals
- Familiarize with Wireshark, Nmap, Burp Suite and Netcat

## 1. Cybersecurity Basics

Topics covered:

- Confidentiality, Integrity and Availability (CIA Triad)
- Phishing
- Malware
- DDoS
- SQL Injection
- Brute Force
- Ransomware
- Social Engineering
- Wireless Attacks
- Insider Threats

## 2. Lab Environment

The planned lab environment includes:

- VirtualBox / VMware
- Kali Linux as the attacker machine
- Metasploitable2 or DVWA as the target
- Private / Host-Only network configuration

## 3. Linux Fundamentals

Topics and commands covered:

- File system navigation: `cd`, `ls`, `pwd`
- File permissions: `chmod`, `chown`
- Package management: `apt`, `dpkg`
- Networking commands: `ip`, `ping`, `ss`, `traceroute`

## 4. Networking Basics

Topics covered:

- OSI Model
- TCP/IP Protocol Suite
- DNS
- HTTP / HTTPS
- IP Addressing
- Subnetting
- NAT

## 5. Cryptography Basics

Topics covered:

- Symmetric Encryption
- Asymmetric Encryption
- Hashing
- MD5
- SHA-256
- Digital Certificates
- SSL/TLS
- OpenSSL encryption and decryption

## 6. Security Tools

Tools covered:

- Wireshark — packet capture and analysis
- Nmap — network and service scanning
- Burp Suite — web security testing
- Netcat — network debugging
