# Cryptography Basics

## Symmetric Encryption
The same secret key is used for encryption and decryption.

## Asymmetric Encryption
A key pair is used: a public key and a private key.

## Hashing

Hash functions produce a fixed-size digest from input data.

Examples listed in the internship brief:
- MD5
- SHA-256

Hashing is not the same as reversible encryption.

## Digital Certificates and TLS

Digital certificates help establish identity and trust in TLS connections.
