# Cybersecurity Basics

## CIA Triad

### Confidentiality
Information is accessible only to authorized users.

### Integrity
Information remains accurate and is not improperly altered.

### Availability
Systems and information remain accessible when needed.

## Threat Types

- Phishing — deceptive communication intended to trick a user.
- Malware — malicious software designed to perform harmful or unauthorized actions.
- DDoS — overwhelming a service with distributed traffic to affect availability.
- SQL Injection — injecting SQL-related input into an application to manipulate database queries.
- Brute Force — repeatedly trying possible credentials or keys.
- Ransomware — malware that can deny access to data, commonly through encryption, and demand payment.

## Attack Vectors

- Social Engineering
- Wireless Attacks
- Insider Threats

All practical testing should be performed only in an authorized lab environment.
