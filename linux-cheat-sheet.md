# Linux Cheat Sheet

## Navigation
```bash
pwd
ls
cd <directory>
```

## Files and directories
```bash
mkdir <directory>
touch <file>
cp <source> <destination>
mv <source> <destination>
rm <file>
```

## Permissions
```bash
chmod <mode> <file>
chown <user>:<group> <file>
```

## Package management
```bash
sudo apt update
sudo apt install <package>
dpkg -l
```

## Networking
```bash
ip addr
ping <host>
ss -tuln
traceroute <host>
```

## Help
```bash
man <command>
<command> --help
```

Use commands in your own Kali/lab environment and capture screenshots of relevant outputs for the report.
