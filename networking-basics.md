# Networking Basics

## OSI Model

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

## TCP/IP Suite

The TCP/IP model groups networking functions into practical layers used by Internet protocols.

## DNS

DNS translates domain names into IP addresses and related records.

## HTTP / HTTPS

HTTP is an application-layer web protocol. HTTPS protects HTTP traffic using TLS.

## IP Addressing

An IP address identifies a network interface for communication.

## Subnetting

Subnetting divides an IP network into smaller logical networks.

## NAT

Network Address Translation maps addresses between network contexts, commonly private and public addressing.

## Useful Linux networking commands

```bash
ip addr
ping -c 4 127.0.0.1
ss -tuln
traceroute 8.8.8.8
```
