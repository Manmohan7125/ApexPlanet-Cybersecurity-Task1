# Tool Familiarization

## Wireshark
Used for packet capture and network traffic analysis.

## Nmap
Used for network/service discovery and scanning in authorized environments.

Example against your own lab target:
```bash
nmap -sV <LAB_TARGET_IP>
```

## Burp Suite
A web security testing proxy used to inspect and modify HTTP requests in an authorized test environment.

## Netcat
A networking utility useful for connectivity testing and network debugging.

Only scan or test systems you own or have explicit permission to test.
